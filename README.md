# 과학SOS · 반례실험실

**오답을 실험 질문으로 바꾸는 중학교 과학 학습지원 도구.**

AI IMPACT: AI for Good 서울 정책 토론 및 해커톤(2026-09-18) 프로젝트.

학생의 예측 이유에서 사고의 단서를 찾고, 교사가 검토한 반례 실험을 통해 설명이 어떻게 바뀌는지 확인합니다.

## 핵심 흐름

1. 학생이 물체가 뜨거나 가라앉을지 예측하고 이유를 작성합니다.
2. AI가 오개념 가설과 근거를 제안합니다. 근거가 부족하면 판단을 보류합니다.
3. 교사가 근거 카드를 확인·수정·보류하고 검토된 대조 실험을 배정합니다.
4. 학생이 관찰 결과와 예측을 비교하고 설명을 수정합니다.
5. 새 조건의 문항으로 재확인하고, 교사가 이전 설명과 비교합니다.

## MVP

- 밀도 1단원, 예측 문항 6개, 대조 실험 3개.
- 학생 화면: 예측 → 관찰 → 설명 수정 → 새 사례 재확인.
- 교사 화면: 근거 카드, 가설 검토, 실험 배정, 설명 변화.
- 교육청 화면: 개념별 집계, 지원 이행, 지원 후 도달 현황.

## 현재 상태

저장소와 기획 문서를 준비한 단계입니다. 앱 코드 및 실행 환경은 아직 없습니다.
기술 스택은 Next.js + Supabase + Vercel이며, 데모에는 가상 데이터를 사용합니다. 계정 연결·인프라 생성은 아직 진행하지 않았습니다.

## 설계 원칙

AI 제안은 확정 진단이 아닙니다. 실험 조건과 정답은 교사 검토를 거쳐 고정하고, AI는 승인된 실험에서만 추천합니다. 개별 답안은 담당 교사용으로 설계하고 교육청에는 최소 집계만 제공합니다. 학교·학생 서열화나 검증되지 않은 숙달 확률을 제시하지 않습니다.

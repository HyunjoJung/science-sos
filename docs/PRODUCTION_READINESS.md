# 프로덕션 준비 기준

마감일은 구현 우선순위나 완료 기준으로 사용하지 않는다.

현재 구현과 실행 방법의 기준 문서는 [서버형 다과목 실행 경로](LEARNING_RUNTIME.md)이다. 이전 1차 HTTP 보완 계획은 Git 이력에 보존되어 있으며, 실제 적용된 코드·시험 결과와 혼동하지 않는다.

실행 경로는 기존 과학 교실(`/`)과 새 다과목 교실(`/learn`)로 구분한다. 새 경로는 독립 서버형 모델 API 워커와 005–009 마이그레이션이 필요하다. 웹 빌드 성공만으로 운영 DB와 AI가 연결되었다고 표시하지 않는다. 모든 시험의 실제 실행 여부, 대상(모의 API/실제 임시 PostgreSQL/호스팅 환경), 결과와 남은 제한을 PR에 남긴다.

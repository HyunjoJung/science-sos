# 해커톤 구현 작업 목록

2026-09-18 · 현재 구현과 후속 과제를 구분합니다. 초기 요구사항은 [PRD](PRD.md), 실제 연결과 운영 제약은 [운영 안내](OPERATIONS.md), 발표 순서는 [발표 안내](PRESENTATION.md)를 참고합니다.

- [x] Next.js + Supabase 인증·DB + Vercel 구성.
- [x] 학생·교사 역할과 반별 접근 제한, 요청 중복 및 기록 버전 검증.
- [x] 학생 예측·이유 → 교사 검토 → 관찰 → 설명 수정 → 새 사례 → 교사 루브릭 흐름.
- [x] AI 가설·원문 근거 카드와 교사 확인·수정·보류. 보류 시 이유 보완 요청.
- [x] 밀도 문항 6개, 고정 대조 실험 3개, 조건 비교·관찰 증거·개념 설명 루브릭 초안.
- [x] 수업 선택 8개. 밀도 외 단원의 교사 승인 탐구 질문·관찰 기록·새 사례.
- [x] 공식 Cursor CLI 워커를 통한 실제 이유 분석. 구조화 응답·인용 검증과 호출 실패 표시.
- [x] TXT·MD·본문 붙여 넣기 자료 등록, 수정, 채팅 활용 여부 설정.
- [x] 자료 근거 채팅, 개인 질문 기록, 교사 피드백과 읽음 상태.
- [x] 반별 토론·답글·공감, 검색과 필터.
- [x] 실제 최신 제출 기준 학습 현황과 답 분포. 정답 선택과 개념 이해를 구분하는 안내.
- [x] 실제 Supabase·Cursor 통합 검증 스크립트와 운영 안내.
- [x] PC 사이드바 글자 잘림과 카드 압축 수정.

완료 표시는 기능 구현 기준입니다. 과학 교사 검토, 실제 학교 운영 준비, 학습 효과 검증까지 완료했다는 뜻은 아닙니다. 밀도 외 모든 단원에 시뮬레이션이 구현된 것도 아닙니다.
